## Featured Project
### [Design and Deployment of a pfSense-Based Network Security Solution – UMET Burkina](docs/projects/pfsense-umet-burkina/README.md)
Bachelor's thesis. Redesign of a flat university network into a segmented, defense-in-depth architecture:
- 5 isolated VLANs with a deny-by-default firewall policy
- Dual-WAN load balancing and failover, redundant switching core with RSTP
- Suricata IDS/IPS, SquidGuard and pfBlockerNG web filtering
- WPA-Enterprise (802.1X / RADIUS) for administrative Wi-Fi
- Validated by six functional tests, including automatic blocking of an Nmap scan
